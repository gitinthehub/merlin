== REPO FACTS ==

- `~/Developer/merlin`, published as github.com/gitinthehub/merlin, live at
  https://merlin-dnd.netlify.app. Static: no package.json, no build step, no bundler, no test
  framework, no ES modules (`type="module"` is blocked on `file://`). Plain `<script>` tags and
  IIFE → `window.*` globals. Zero-dependency Node scripts are fine for local tooling.
- The arc pipeline: `arcs/pale-hand.json` is the source; `node tools/build-arc.js --from
  arcs/pale-hand.json --out arcs/pale-hand.js` produces the keyless bundle the browser loads, and
  refuses to write when `arc.js`'s `validateArc` reports any error. `arcs/last-signal.json` /
  `arcs/last-signal.js` are the same shape. The bundle must contain no `import `, no `export `, no
  `XAI_API_KEY`, no `OPENAI_API_KEY`, no `Bearer`.
- Engine mechanics you must work within: a choice's roll is `roll: {die, tier, tags}` — a `tier`
  (`easy` / `medium` / `hard` / `veryHard`), never a literal DC for a `d20`; the cast's traits carry
  `difficulty` and `advantage`, and `characters.js` resolves the final number. Consequences are
  `success` / `failure` / `complication` / `bonus`, each with `text`, `next` and optional `resolves`.
  Endings carry `resolves`. `validateArc` walks the graph: unreachable nodes, cycles, unknown `next`,
  a character without a thread, and any path that leaves a thread unsettled are errors. A choice
  cannot be roll-free, so "automatic" in the owner's source prompt means "the easiest tier".
- `run.history` (one entry per resolved choice) and `run.diceLog` exist in `loop.js` and are saved by
  `persist.js`; `stories.js` classifies a save as `empty` / `ready` / `resolved` / `foreign` /
  `unusable` and exposes `saveStatus()` and `savedArc()`. `oronath-ui.js` renders the picker, the
  title screen, a chapter, an outcome and a resolution.
- Frozen this pass — their diffs must be empty: `dice.js`, `arc.js`, `characters.js`, `loop.js`,
  `persist.js`, `dice-view.js`, `sample-arc.js`, `engine.js`, `ui.js`, `data.js`, `style.css`.
  `oronath-ui.js`, `oronath.css`, `stories.js`, `oronath.html`, `index.html`, `roadmap.html`,
  `roadmap.js`, `ROADMAP.md`, `README.md`, `tools/build-arc.js`, `arcs/*`, `tests/*` are editable.
- Tests are zero-dependency Node scripts run from the repo root, e.g. `node tests/pale-hand.test.js`;
  they load modules with relative `require` and mock `localStorage`. `tests/harness.html` is the
  browser view of the engine tests and loads only files that exist.
- `ROADMAP.md` and `roadmap.js` both carry the milestone list and have drifted a whole pass behind
  twice. Any status or name change lands in both, in the same commit. `.pale-hand-arc-spec.md` is the
  content contract for the arc and `.qa/` holds review material.
