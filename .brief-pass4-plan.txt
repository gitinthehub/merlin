## Context

This repository is a shipped, live, static game — vanilla HTML/CSS/JS, no build step, no dependencies, no network requests at runtime:

- `index.html` — shell
- `style.css` — gothic candlelight UI
- `data.js` — content: characters, items, shops, encounters, 22-node scene graph (`window.MERLIN`)
- `engine.js` — pure logic, no DOM (`window.MerlinEngine`): rolls, combat, economy, localStorage save
- `ui.js` — typewriter, character sheet, shops, combat UI
- `README.md`, `ROADMAP.md`

Live at https://merlin-dnd.netlify.app. Autosave is `localStorage` key `merlin.save.v1`, written on every scene change, shop transaction, level-up and combat turn; a refresh resumes mid-scene and mid-fight. Four endings (`end_stake`, `end_clause`, `end_board`, `end_fled`) plus `death` (An Epitaph, which already has cause-specific text for `ghoul`, `wight`, `count`, `fall`, `marsh`).

READ `ROADMAP.md` FIRST. It is the source of truth, and the four ideas below are quoted there verbatim in the "Top 4 ideas" section.

## Task

Produce an implementation plan for exactly these four items (roadmap 1.3–1.6). Nothing else — no dice-animation work, no art wiring, no roadmap page; those are a separate pass.

**1.3 The Count's Epitaph Card (M).** Every ending, deaths included, produces a shareable image card. It shows the character, the ending title, a few run stats (nat 20s, nat 1s, gold wasted), and one custom line from the Count, like "Died to a ghoul. A GHOUL. Not a wizard." Add a single "Copy / Save image" button with the site URL on the card.

**1.4 Fates Ledger with hints from the Count (S).** An endings screen that shows which endings you've found and which are still locked. For each locked one, the Count gives a snide, slightly useful hint ("There is an ending where you live and I am improved. You won't find it."). Store it in its own save slot so "New Game" doesn't wipe it.

**1.5 He Remembers You (M).** Carry a little memory between runs: the last character you played, how you died, and which ending you got. The Count and Clarence bring it up ("You again. Last time you fled. Clarence logged it.").

**1.6 Call Him a Wizard (S–M).** Optional dialogue choices where you deliberately call him Merlin the wizard. A hidden counter tracks how many times you do it. Each jab has a real cost or benefit: he gets flustered and his next telegraphed move is weaker, or he gets furious and hits harder. Enough jabs unlock a secret ending or a special epitaph.
